# Conventions

Committed coding conventions for the repo. These are the canonical specs
reviewers hold changes to; where a rule is enforced by tooling, it says
so, and the guide's Enforcement section maps each one to the rule that
catches it.

- [web-style-guide.md](web-style-guide.md) — TypeScript, React, and CSS
  conventions for `apps/web` and the packages it consumes.
- [markdown-style-guide.md](markdown-style-guide.md) — markdown across
  the repo, including where prose wraps and where it does not.

Python (`apps/api`), Go (`apps/cli`), and shell conventions can join as
siblings here when they are written down; for now they live in the code
and in CONTRIBUTING.
